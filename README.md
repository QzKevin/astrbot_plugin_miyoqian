# astrbot_plugin_miyoqian

> 米游社全游戏每日自动签到 —— 绑定一次，每天准点替你打卡。

一款为 [AstrBot](https://github.com/Soulter/AstrBot) 开发的米游社签到插件，覆盖 **原神 / 崩坏：星穹铁道 / 崩坏3 / 绝区零 / 崩坏学园2 / 未定事件簿**（国服）。
支持扫码登录、Cookie 绑定、多账号多角色、每日定时自动签到。

## 功能概览

- **自动签到** 默认每天 `10:00` 全账号自动签到
- **自动推送** 自动签到完成后，会向绑定者推送结果，包括签到成功、失败、异常等。
- **扫码登录绑定** 「米游社 扫码」，米游社 App 扫二维码自动绑定
- **多账号支持** 可绑定多个米游社账号，「米游社 切换 <序号>」切换

- **新版 API 支持** 原神、绝区零走新版签到 API（`x-rpc-signgame` + `act.mihoyo.com`），行为贴近新版 App，能规避旧版接口在这两款游戏上的签到异常。

## 快速上手

1. 把 `astrbot_plugin_miyoqian` 文件夹放进 `/data/plugins/`
2. 给机器人发 **`米游社 扫码`**，用米游社 App 扫它返回的二维码并确认登录
3. 给机器人发 **`米游社 签到`**，测试能否成功签到

> 群聊里指令要加 `/` 前缀（如 `/签到`）或 @ 机器人

## 指令一览

| 指令 | 说明 |
| --- | --- |
| `签到` | 一键签到当前账号的全部游戏（快捷指令） |
| `米游社 扫码` | 扫码登录自动绑定（建议私聊使用） |
| `米游社 绑定 <cookie>` | 绑定 Cookie |
| `米游社 签到 [游戏]` | 指定游戏签到，不填则全部 |
| `米游社 查询 [游戏]` | 查询本月签到状态 |
| `米游社 我的` | 查看所有绑定账号 |
| `米游社 切换 <序号>` | 多账号切换默认账号 |
| `米游社 解绑 [全部]` | 解绑当前账号（加「全部」解绑所有） |
| `米游社 全部签到` | 管理员：全员立即签到 |
| `米游社 帮助` | 使用帮助 |

## 绑定账号

### **#01 米游社App扫码（推荐）**
— 发 `米游社 扫码`，拿到二维码图片后用米游社 App 扫一下，确认登录即自动完成绑定。

### **#02 手动获取并添加 Cookie** 
— 如果扫码不方便，按下面几步拿 Cookie：
1. 浏览器**无痕模式**打开并登录 `https://user.mihoyo.com/`
2. `F12` 打开开发者工具，切到 **Console（控制台）**
3. 输入 `document.cookie` 回车，复制输出的内容
4. 发给机器人：`米游社 绑定 <复制的内容>`


## 配置项

| 配置项 | 说明 | 默认 |
| --- | --- | --- |
| `sign_time` | 每日自动签到时间（`HH:MM`，北京时间） | `10:00` |
| `push_result` | 自动签到后是否推送结果 | `true` |
| `games` | 各游戏自动签到开关 | 原神/崩铁/崩3/绝区零默认开启 |
| `qr_timeout` | 二维码有效时间（秒） | `120` |
| `api_retries` | API 失败自动重试次数 | `3` |

进阶项：

| 配置项 | 说明 | 默认 |
| --- | --- | --- |
| `act_id_override` | 活动 ID 覆盖，如 `{"hk4e_cn": "新ID"}` | 空 |
| `ds_salt` | DS 签名盐（新版网页端 salt） | `G1ktdwFL4IyGkHuuWSmz0wUe9Db9scyK` |
| `app_version` | `x-rpc-app_version` | `2.109.0` |
| `client_type` | `x-rpc-client_type`（5=移动网页端，2=安卓端） | `5` |
